Build a photo editor that runs in the browser, like Adobe Photoshop software: open an image, edit it with the usual tools, and save the result.

- It should have what people expect from a desktop photo editor: a toolbar of tools, layers, filters and adjustments, undo and redo, zoom, and export.
- Plain HTML, CSS and JavaScript in this folder. No build step, no packages, no network calls, no external fonts or CDNs. It must work by opening index.html in Chrome. Images never leave the page.
- Give it its own name. Do not use the words Adobe or Photoshop anywhere in the app or its files, and do not copy any Adobe logo, icon, layout or color scheme.
- Write automated tests for it, run them in the foreground, and wait for them.
- README: what it does, how to open it, and what it can't do yet.
